# 📊 Power BI Sales Analytics Dashboard

An interactive **3-page Sales Analytics Dashboard** built using Microsoft Power BI to explore sales performance, product trends, customer insights, and regional distribution.

This project demonstrates the use of data transformation, data visualization, DAX measures, and interactive reporting to turn raw sales data into meaningful business insights.

## ✨ Key Features

- **Executive Overview:** High-level view of overall sales performance.
- **Product Analysis:** Explore product-level sales trends and performance.
- **Customer Insights:** Analyze customer-related sales patterns.
- **Regional Analysis:** Understand sales distribution across different regions.
- **Interactive Slicers:** Dynamically filter and explore dashboard data.
- **Custom DAX Measures:** Create calculated metrics for meaningful analysis.
- **Interactive Navigation:** Navigate between dashboard pages seamlessly.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Power BI | Dashboard development and visualization |
| Power Query | Data cleaning and transformation |
| DAX | Calculated measures and analytical metrics |
| Microsoft Excel | Source dataset |

## 🚀 Getting Started

### Prerequisites
- Microsoft Power BI Desktop
- Microsoft Excel (optional, for exploring the source dataset)

### How to View the Dashboard

1. Clone or download this repository.
2. Locate the `Sales Dashboard.pbix` file.
3. Open it using Microsoft Power BI Desktop.
4. Explore the three dashboard pages using the interactive navigation and slicers.

## 🎯 Project Objective

The primary objective of this project is to demonstrate how business intelligence tools can be used to analyze sales data, identify patterns, and present information through interactive visualizations.

It also provides practical experience with Power BI, Power Query, DAX, and dashboard design.
